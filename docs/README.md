# Documentation

| Guide | Read it when |
| --- | --- |
| [Getting started](./getting-started.md) | You want a fixture replaying in a test in the next ten minutes. |
| [Matching](./matching.md) | A request is not matching, or is matching when it should not. |
| [Explained mismatches](./explain.md) | You want to understand the failure report, or extend it. |
| [Redaction](./redaction.md) | Before you record against anything real. |
| [CLI reference](./cli.md) | You are using `spool` from a shell or CI. |
| [Migrating](./migrating.md) | You already use VCR, nock, MSW, or HAR files. |
| [Design decisions](./design-decisions.md) | You want to know why something works the way it does. |
| [Contributing an adapter](./contributing-adapters.md) | Your HTTP client is not covered. |
| [Contributing an implementation](./contributing-implementations.md) | You want to port HIF to another language. |
| [FAQ](./faq.md) | Quick questions. |

The [specification](../specification/hif-1.0.md) is the normative reference. These
guides explain and illustrate; where they disagree with the spec, the spec wins
and the guide has a bug.
